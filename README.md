## Структура репозиторію

* **`lab01/`** — Лабораторна робота №1: «Кореляційний аналіз у задачах виявлення прихованих об’єктів».
  * `api.py` — REST API клієнт для взаємодії з акустичним сервером ехолота (`/api/config`, `/api/pulse`, `/api/sensor?step=...`).
  * `math_dsp.py` — алгоритми цифрової обробки сигналів (DSP) на чистому Python без зовнішніх бібліотек (обчислення взаємної кореляції $R(k)$, пошук піку затримки та розрахунок глибини, синхронне накопичення сигналів).
  * `ui.py` — віконний графічний додаток (Tkinter Plain UI) з анімацією руху судна, ультразвуковим сонарним променем, двома осцилографами та панеллю телеметрії.
  * `main.py` — точка входу запуску програми.
  * `client.py` — модуль експорту математичних функцій.

* **`lab02/`** — Лабораторна робота №2: «Оптимізація багатоекстремальної функції в дискретному просторі з обмеженнями з використанням алгоритму імітації відпалу».
  * `api.py` — REST API клієнт для взаємодії з сервером середовища Fox Hunt (`/api/start`, `/api/move`).
  * `simulated_annealing.py` — алгоритм імітації відпалу (Simulated Annealing): критерій Метрополіса $P = \exp(\Delta E / T)$, динамічний радіус пошуку $R(T)$, геометричне охолодження та механізм повторного нагрівання (Reheating) при захопленні об'єкта.
  * `ui.py` — віконний графічний додаток (Tkinter) з динамічною візуалізацією карти $100 \times 100$, перешкод, траєкторії агента, точок знайдених лисиць та графіком охолодження.
  * `main.py` — точка входу запуску (підтримка як GUI, так і CLI режиму `--cli`).

* **`lab03/`** — Лабораторна робота №3: «Розв'язання комбінаторної задачі розміщення з обмеженнями з використанням генетичного алгоритму та алгоритму імітації відпалу».
  * `model.py` — обчислювальна модель морського поля `BattleshipBoard`: валідація конфігурації поля $7 \times 7$, розрахунок координат клітинок, перевірка виходу за межі поля, зіткнень з рифами, накладань та дотиків кораблів (8-зв'язність), функції пристосованості (Fitness) та енергії порушень (Energy).
  * `genetic_algorithm.py` — генетичний алгоритм (GA, Завдання 3.1): цілочисельне кодування хромосом, турнірний відбір ($k=4$), однорідний кросовер (Uniform Crossover), випадкова мутація положення та орієнтації зі зсувом, механізм елітизму.
  * `simulated_annealing.py` — алгоритм імітації відпалу (SA, Завдання 3.2): генерація сусідніх станів з локальним збуренням генів, критерій прийняття гірших станів Метрополіса $P = \exp(-\Delta E / T)$, експоненціальний закон охолодження $T_{k+1} = \alpha T_k$, динамічний трекінг температури та коефіцієнта прийняття.
  * `ui.py` — віконний графічний додаток (Tkinter) у світлому стилі: сітка $7 \times 7$, відображення рифів та флотилії кораблів кольоровими сегментами з номерами, підсвічування порушень червоним контуром, живі графіки збіжності цільової функції та динаміки охолодження, перемикання GA / SA в реальному часі.
  * `main.py` — єдина точка входу (GUI режим та CLI бенчмаркінг: `--cli --algo [ga|sa|both] --runs [n]`).
  * `variant02.json` — конфігурація Варіанта 2 (поле $7 \times 7$, 26 рифів, 10 кораблів).

* **`lab04/`** — Лабораторна робота №4: «Керування інерційним об'єктом з використанням табличної політики, навченої генетичним алгоритмом, на прикладі стикування космічного корабля».
  * `client.py` — TCP-клієнт взаємодії з симулятором DockSim по протоколу JSON (`hello`, `reset`, `step`, `state`, обробка помилок `error`).
  * `policy.py` — таблична політика `TabularPolicy`: дискретизація відносних ознак (похибка курсу $\delta$ з упередженням $T$, кутова швидкість $\omega$, проекція похибки швидкості), роздільні таблиці повороту (Turn Table, 9 клітинок) та тяги (Thrust Table, 6 клітинок), кодування/декодування хромосоми.
  * `genetic_algorithm.py` — генетичний алгоритм оптимізації політики `GeneticAlgorithmTrainer`: турнірний відбір, однорідний кросовер, мутація дій у клітинках та порогів, багатопотокова паралельна оцінка особин у середовищі DockSim.
  * `manual.py` — модуль ручного керування `ManualController`: трансляція натиснутих клавіш `keys` у команди керування `(thrust, turn)`.
  * `ui.py` — віконний графічний додаток (Tkinter) у світлому стилі: візуалізація польоту корабля, станції та уламка, траєкторія руху, телеметрія стикування, живі графіки фітнесу та висоти.
  * `main.py` — точка входу запуску (підтримка GUI, ручного режиму, навчання ГА `--train` та офіційного заліку `--eval-auto`, `--eval-manual`).

## Запуск лабораторних робіт

### Лабораторна робота №1
```bash
cd lab01
python main.py
```

### Лабораторна робота №2
```bash
python -m lab02.main --variant 2
```

### Лабораторна робота №3
```bash
# Графічний інтерфейс (GUI)
python -m lab03.main --variant 2

# Консольний бенчмаркінг (CLI)
python -m lab03.main --cli --algo both --runs 5
```

### Лабораторна робота №4
```bash
# Графічний інтерфейс (GUI)
python -m lab04.main

# Навчання генетичного алгоритму (CLI)
python -m lab04.main --train --generations 15 --pop-size 30

# Офіційний залік навченої моделі (Evaluate Auto)
python -m lab04.main --eval-auto

# Офіційний залік ручного керування (Evaluate Manual)
python -m lab04.main --eval-manual
```
