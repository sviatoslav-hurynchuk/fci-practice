## Структура репозиторію

* **`lab01/`** — Лабораторна робота №1: «Кореляційний аналіз у задачах виявлення прихованих об’єктів».
  * `api.py` — REST API клієнт для взаємодії з акустичним сервером ехолота (`/api/config`, `/api/pulse`, `/api/sensor?step=...`).
  * `math_dsp.py` — алгоритми цифрової обробки сигналів (DSP) на чистому Python без зовнішніх бібліотек (обчислення взаємної кореляції $R(k)$, пошук піку затримки та розрахунок глибини, синхронне накопичення сигналів).
  * `ui.py` — віконний графічний додаток (Tkinter Plain UI) з анімацією руху судна, ультразвуковим сонарним променем, двома осцилографами та панеллю телеметрії.
  * `main.py` — точка входу запуску програми.
  * `client.py` — модуль експорту математичних функцій.

* **`lab02/`** — Лабораторна робота №2: «Оптимізація багатоекстремальної функції в дискретному просторі з обмеженнями з використанням алгоритму імітації відпалу».
  * `api.py` — REST API клієнт для взаємодії з сервером середовища Fox Hunt (`/api/start`, `/api/move`).
  * `simulated_annealing.py` — алгоритм імітації відпалу (Simulated Annealing): критерій Метрополіса $P = \exp(\Delta E / T)$, динамічний радіус пошуку $R(T)$, геометричне охолодження та механізм повторного нагрівання (Reheating) при захопленні об'єкта.
  * `ui.py` — віконний графічний додаток (Tkinter) з динамічною візуалізацією карти $100 \times 100$, перешкод, траєкторії агента, точок знайдених лисиць та графіком охолодження.
  * `main.py` — точка входу запуску (підтримка як GUI, так і CLI режиму `--cli`).
