# Основи обробки інформації (ООІ) — Практичні та лабораторні роботи

Репозиторій практичних та лабораторних робіт з дисципліни «Основи обробки інформації».
Студент: **Гуринчук Святослав**

## Структура репозиторію

* **`lab01/`** — Лабораторна робота №1: «Кореляційний аналіз у задачах виявлення прихованих об’єктів».
  * `api.py` — REST API клієнт для взаємодії з акустичним сервером ехолота (`/api/config`, `/api/pulse`, `/api/sensor?step=...`).
  * `math_dsp.py` — модулі алгоритмів цифрової обробки сигналів (DSP) на чистому Python без зовнішніх бібліотек (обчислення взаємної кореляції $R(k)$, пошук піку затримки та глибини, синхронне накопичення).
  * `ui.py` — віконний графічний інтерфейс користувача (Tkinter Plain UI) з анімацією руху судна, сонарним променем, двома осцилографами та живою телеметрією.
  * `main.py` — точка входу запуску програми.
  * `client.py` — модуль сумісності та експорту розрахункових функцій.

## Запуск лабораторної роботи №1

```bash
cd lab01
python main.py
```
